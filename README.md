<h1 align="center">Datum Sim</h1>

<p align="center">Model and simulate dynamic systems: block diagrams, control design and physical components.</p>

Draw a model, press Run, and see how the system behaves over time. Datum Sim is for control, mechanical, electrical, process and mechatronics engineers, researchers and students.

It is part of [Datum](https://edgar-mendonca.github.io/Datum/), a family of free and open-source (MIT) desktop tools for engineers and scientists. It is Windows first, installs in seconds and updates itself.
