Bugs found and fixed:
- The 3D view's canvas was removed by the window's own re-render; it now has a container of its own.
- The real app's security policy blocked the window from loading its own mesh files. Found in the real app; a UI check now reads the policy.
- The arm, controller and payload waited for each other's signal widths. Blocks now tell the compiler the widths their parameters fix.
- In the first pick-and-place draft, the box's resting height left it just outside the gripper's capture distance.

Not verified here:
- Contact is only between the payload and its table. The robot's links do not collide with the table, the box or themselves.
- The 7-joint arm's fingers do not move.
- Tool paths have no arcs or orientation changes.
- Loop Analysis of a joint loop: analysis points take single signals, and an arm's loop carries all its joints.
- None of this has been used on a Windows PC.
