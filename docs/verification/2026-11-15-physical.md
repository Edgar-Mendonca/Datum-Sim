Bugs found and fixed:
- **Pulse and Square wave lost pulses** at fast edges with the variable-step solvers. An edge reached a rounding error early, and its old level was held through the next step. A 10 kHz pulse averaged 0.435 instead of 0.5. Fixed by snapping the phase at the period's end. Test: `fast_pulse_edges`, which fails on the old code.
- **Diodes could be solved in the wrong state** within a step, dumping an inductor's energy through the off-state leakage. Each evaluation now settles every diode to a consistent state. Test: the buck converter's mean.
- **A signal connected to a part's input 1 removed a physical connection** ending on that part's physical port 1, and the window showed the input as connected. Test: `machines_on_ports`; UI check "a physical connection does not mark a signal input as connected", which fails on the old window.
- **Newton stopped too early** in networks whose unknowns differ in scale (pressures of 10⁷ Pa beside flows of 10⁻⁴ m³/s): a cylinder ran 36 % slow. Each unknown now meets its own tolerance. Test: `hydraulic_parts`. The test run also dropped from 358 305 to 1 565 steps.
- The PhysNet block's spurious algebraic-loop warning (a speed sensor reads a state): its feedthrough is now found by probing.

Not verified here:
- Parts with no test of their own yet: backlash, translational friction, the pipe, the accumulator, the valve, the smooth diode, the current sources, the velocity source and the force, heat-flow and flow sensors. They use the same elements as tested parts, but each is not yet checked against a known answer of its own.
- Higher-index networks beyond the reported errors: loops of across sources and capacitances are refused, not solved.
- Physical connections across subsystem edges (not supported yet).
- Large networks' speed: every evaluation solves the network's algebraic part with a finite-difference Jacobian. This is fine for the examples (tens of unknowns), untested beyond that.
- Compressible flow beyond the bulk modulus, cavitation, fluid temperature.
- The installers on a Windows PC: the release builds ran on GitHub's Windows machines, but the user has not yet run 0.5.1 to 0.6.0 on a PC.
