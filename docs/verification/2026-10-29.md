## Window

- UI checks (`tests_ui/run.cjs`, 33 in all, 3 new): sample-time colours mark the blocks, the legend names the rates, and turning them off removes them.
- In the real app under Xvfb: the digital PMSM drive runs (speed, braking, the DC link rising) and the sample-time colours show 10 kHz, 1 kHz, constant and mixed blocks with the legend.

## Bugs these checks found

- A zero-crossing function resting at exactly zero (the reset input between pulses) made the solver find a "crossing" on every step and take endless tiny steps. A crossing now goes strictly from one side to the other; the last non-zero sign is still kept, so the switched inverter test from 0.1.2 passes.

## Not verified

- The stepper motor's power balance (it is checked by its step angle only).
- Sample offsets (a sample time that starts later than 0) are not supported yet.
- The discrete blocks are not linearised for the Bode plot (analysis works on continuous blocks).
- Not yet run on Windows (CI builds and tests there).
